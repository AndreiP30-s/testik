# Что изменено относительно techstore-lab2

1. Исходная папка и её локальная база не менялись. Новая версия находится отдельно.
2. PostgreSQL перенесён в Compose: отдельный проект, порт 5434, named volume,
   автоматическая инициализация SQL и проверка готовности.
3. Оставлен один набор JPA-моделей. Отдельные ProductEntity/UserEntity и mapping
   удалены. Модели находятся в model, репозитории — в repository.
4. Вместо Smartphone/Laptop/Tablet/Headphones используется Product с категорией и
   характеристиками. Их конструкторные проверки перенесены в ProductRules.
5. User стал абстрактной JPA-сущностью с SINGLE_TABLE. ADMIN/MANAGER/CUSTOMER
   определяют подкласс через существующий role; UUID-преобразования удалены.
6. Контроллеры и DTO сохранены. JSON-контракт товаров и пользователей прежний.
7. Скидки используют PriceSnapshot вместо копирования товара в другую модель.
   Исходные цены и состояние скидки по-прежнему хранятся в БД.
8. Удалены консоль, in-memory репозитории, legacy-профиль и относящиеся к ним тесты.
9. Перенесены REST-регрессии, добавлены проверки новой валидации и расчётов.
10. README и примеры обновлены для нового запуска. Пароль прежнего PostgreSQL
    и файлы .local/.idea не копировались.

Схема бизнеса не менялась: SQL из другого предмета остаётся основой.
Дополнительные таблицы поддержки скидок и последовательность артикулов сохранены.

## Дополнение: контракты сервисов и Swagger

ProductService, UserService, ReferenceService, DiscountService стали интерфейсами.
Прежний код находится в service.impl, в классах с суффиксом Impl. Контроллеры
и тесты получают интерфейсы через Spring; дополнительные преобразования моделей
или таблицы не добавлялись.

Swagger доступен на /swagger-ui.html, спецификация на /v3/api-docs. Это интерфейс
для отправки HTTP-запросов, а не отдельная реализация бизнес-логики.
