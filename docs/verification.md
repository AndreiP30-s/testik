# Проверка упрощённой Docker-версии

Дата: 16 ноября 2026.

## Сборка и unit-тесты

`clean verify` выполнен на Temurin JDK 17.0.21.
Результат: **58 тестов, 0 ошибок, 0 падений, 0 пропусков, BUILD SUCCESS**.
Актуальный clean verify со Swagger выполнялся при остановленной Docker-базе. Тестовый профиль отключает
DataSource, Hibernate и создание JPA-репозиториев; вместо них используются Mockito-моки.
Отдельный тест подтверждает отсутствие DataSource и EntityManagerFactory.

Проверяются REST CRUD, фильтры и ошибки, BCrypt, создание подклассов пользователей,
справочники, скидки, обязательные характеристики всех категорий, положительные числа,
перечисления, частоты, группы камер и многопоточный расчёт по неизменяемым снимкам.

В предыдущей версии было 100 тестов, включая консоль и преобразование двух моделей.
Этот код удалён из новой версии; соответствующие тесты не переносились. Проверки
нового ProductRules добавлены вместо конструкторных проверок прежних товаров.

## Docker и реальная БД

Запущен официальный образ postgres:18 (при проверке PostgreSQL 18.7).
Compose создал отдельный контейнер, сеть и named volume. При первом старте автоматически
выполнены три SQL-файла; создано 12 таблиц. PostgreSQL доступен только на localhost:5434.
JPA запущен с ddl-auto=validate и успешно проверил отображение схемы.

## HTTP-проверки отдельно от unit-тестов

- Первый этап: 43 HTTP-проверки CRUD четырёх типов товаров, характеристик, камер,
  фильтров, пользователей, справочников и скидок.
- Приложение остановлено, контейнер удалён через compose down без удаления volume,
  затем пересоздан. Данные, роли и активная скидка сохранились.
- После перезапуска исходные цены восстановлены из discount_backup.
- Проверены создание и чтение ADMIN/MANAGER/CUSTOMER, загрузка по роли и смена роли
  с последующим чтением из БД. Таблица одна; роль определяет конкретный JPA-подкласс.
- Три серии по 10 одновременных POST одного email: в каждой один 201 и девять 409.
- Четыре параллельных применения скидки: одно 200, три 409; цена изменена один раз.
- Удаление товара с позицией заказа возвращает 409. Транзакция восстанавливает
  характеристики и камеры; пользователь с заказом также остаётся после отказа удаления.
- В Docker-базе оставлен один пример смартфона. Остальные проверочные записи убраны.

Все записи и проверки выполнялись в новой Docker-базе. Прежняя папка techstore-lab2,
её база на PostgreSQL localhost:5432, пароль и запущенное приложение не изменялись.

Map<Long,...> и .longValue() из скидок удалены.
make build на Java 17: **63 теста, 0 ошибок, 0 падений, BUILD SUCCESS**.
